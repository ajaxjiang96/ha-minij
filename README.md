# 小吉 MiniJ · Home Assistant 集成

<img src="custom_components/minij/brand/icon.png" alt="小吉 App 图标" width="80">

非官方的小吉 **云端监测与控制** 集成，已在 V6-XNB 壁挂洗烘机
（内部型号 `minij.washer.x68`）完成本轮登录、监测和主要控制验收。
通过小吉账号接入，无需在日常使用时运行 APK 或模拟器。

**控制测试版：0.4.0b5**；稳定渠道仍为仅含早期监测功能的 0.1.1。
控制功能请安装测试版，实际下载以 [GitHub Releases](https://github.com/ajaxjiang96/ha-minij/releases) 为准。
仓库文档优先使用简体中文，HA 界面跟随用户语言，提供简体中文和英文。

## 已支持的功能

| 类别 | 功能与行为 |
| --- | --- |
| 状态监测 | 待机、已唤醒、工作中、已暂停和设备上报异常；保留未知别名与原始文字 |
| 程序与进程 | 显示机器实际上报的洗涤程序和阶段 |
| 剩余时间 | V6-XNB 工作时显示云端上报分钟数，不在本地倒计时；暂停、空闲等状态显示未知 |
| 设备通知 | 官方洗衣完成、清洁完成和故障消息事件；自动化通知由用户配置 |
| 程序与参数 | 本机提供的22个程序、7类参数：水位、温度、漂洗、烘干、烘干强度、蒸汽除菌、UVC筒灯；允许值随程序变化 |
| 洗涤控制 | 唤醒、启动待选程序、暂停、继续、停止／关机；App 的停止与关机为同一操作 |
| 设备设置 | 提示音、童锁及云端授权状态；童锁控制已有云端上报变化，面板效果仍待单独确认 |
| 智能清洁 | 清洁提醒、提醒次数、立即筒清洁；仅在设备提供声明时显示托管设置 |
| 诊断 | 缓存状态、程序/参数摘要及最近30条脱敏控制请求 |

在本次 V6-XNB 上共加载25个实体。新安装默认启用控制，已有 HA 手动禁用设置保留。
唤醒、启动、暂停、继续、停止／关机、提示音及本轮参数有所有者观察或云端读回证据；
覆盖范围见[控制指南](docs/local-controls-0.4.md)与[验收记录](docs/validation.md)，不推广为所有机型、固件和参数组合均已验证。

正常每60秒共享一次设备列表读取，错误逐步退避至900秒，限流至少等待300秒。
成功读取时同步云端名称、型号和固件，保留 HA 自定义名称、区域及已有实体标识。
云端刷新失败或解绑时实体不可用；未知开关值保留未知。

当前验收基线：Wi-Fi `1.0253`，设备固件 `0 0003 1 0000`。
其他型号和固件可以提供脱敏反馈，安装成功本身不等于控制已验证。

## 安装

推荐按照 [HACS 自定义仓库指南](docs/hacs-installation.md)安装和更新。
在 HACS 启用**显示测试版 / beta**，选择 `v0.4.0b5` 体验监测与控制；
仅选择稳定渠道将得到早期监测版 `v0.1.1`。
以下是手动安装方式：

需要 **Home Assistant 2026.10.4 或更新版本**。

1. 将仓库中的 `custom_components/minij` 完整复制到 HA 配置目录的
   `custom_components/` 下，包含 `translations/` 子目录。
   也可执行 `python scripts/package_integration.py`，将生成的 ZIP 解压到 HA 配置目录。
2. 重启 Home Assistant。
3. 打开 **设置 → 设备与服务 → 添加集成 → MiniJ**。
4. 选择**手机验证码（实验功能）**或**已有会话令牌（高级）**。
5. 手机号使用已有小吉账号的 11 位中国大陆号码，不带 `+86`。
   提交号码才会发送一条短信，再输入短信验证码即可。

验证码和令牌使用遮挡输入框。配置中只保存验证后的会话令牌，不保存手机号或验证码。
账号与设备访问检查失败时，“重试”只重复读取，不会再次发送短信或兑换验证码。
更换号码或重新获取短信需取消后重新开始，请避免重复请求。

已有条目可从 **⋮ → 重新配置** 更新认证，不需要删除设备；重新认证必须使用原账号。
账号所有者反馈短信流程可用，且本次登录后手机 App 仍能直接查看设备；
也已观察到 HA 启动后自动恢复，无需短信。长期有效期、其他会话轮换情形、
验证码冷却和额外验证仍未完整确认。遇到不支持的验证步骤，可使用自己的 App 会话令牌。
详见[登录验证指南](docs/sms-acceptance.md)和[认证证据](docs/authentication.md)。

源码：[ajaxjiang96/ha-minij](https://github.com/ajaxjiang96/ha-minij)。
HACS 自定义仓库无需等待默认列表收录。
各版本范围见[0.4.0b5 发布说明](docs/releases/0.4.0b5.md)与[支持政策](docs/support.md)。

## 使用控制

先在“待启动程序”选择程序，核对随之更新的参数，再按“启动待选程序（实验）”。
选择本身是本地草稿，不会启动机器；重启后使用云端目录初值，启动前应明确选择所需程序。
只唤醒机器则按“唤醒（实验）”。

暂停和继续每次读取实际运行程序，不使用待启动草稿；“停止／关机（实验）”会尝试结束当前程序并关机。
所有控制只发送一次，不自动唤醒或重发，也不把云端接受直接显示为机器已执行。
状态由后续云端读取更新，可能稍有延迟。完成测试后先下载诊断，再重启或重载；命令台账不跨重载保存。

本次发布使用已在所有者 HA 本地验收的 b5 运行代码，详见[控制与参数指南](docs/local-controls-0.4.md)。

- [完成与故障通知蓝图](docs/automations.md)：在 HA 界面选择洗衣机、消息类型和通知动作，默认创建 HA 内部通知，也可配置手机推送。

## 当前限制

- **运行后回到空闲，不等于已确认正常完成。** 取消、停止等情况尚未区分；
  本版仅根据独立的官方完成消息产生事件，不根据回空闲或剩余时间 0 推断；
  通知由用户自行配置，故障/停机窗口不补报。
- 空闲时的程序和进程可能保留先前值，不能仅凭“主洗”“脱水”等文字判断仍在运行。
- 本版提供经 V6-XNB 对照的剩余分钟数；其他阶段、暂停和特殊值尚待完整核对，
  不提供预计结束时间。其他型号不据此启用时间实体。
- 可用性表示云端读取和设备绑定情况，尚不能代表设备的物理联网状态。
- `device_exception` 本身不能说明具体故障原因。
- 未假设令牌有效期或刷新接口；状态读取收到 HTTP 401/403 时进入重新认证。
- 当前测试版提供实验唤醒、启动、暂停、继续和停止／关机；不提供固件管理、局域网控制或 MQTT。

测试版名称不表示全部场景或长期行为已完成验证。无需为了发布额外运行洗涤；
有正常使用机会时，再补充验证即可。

## 诊断与支持

MiniJ 条目的 **下载诊断信息** 提供已缓存的型号、固件和白名单状态字段，
不会额外轮询、发送短信或操作设备。MiniJ 数据部分不包含凭据或小吉标识符；
HA 会在外围添加系统信息，分享前请检查。
