# 洗衣机仪表盘模板

使用 [examples/dashboard.yaml](../examples/dashboard.yaml) 把状态、待启动程序、动态参数和启停按钮放在一张卡片中。
仅使用 HA 原生的实体、按钮、网格和 Markdown 卡片，无需 Mushroom、card-mod 或其他前端插件。
适用于已安装 `0.4.0b5` 控制测试版的 V6-XNB；这是 0.5 的配套模板，不需要先升级集成或安装新包。

## 添加到界面

1. 在 **设置 → 设备与服务 → MiniJ → 设备** 中打开洗衣机。
   分别打开所需实体的设置，复制实际的实体 ID。名称可能受 HA 语言、历史安装及用户改名影响，不能直接猜测 ID。
2. 下载或复制 `examples/dashboard.yaml`。按下表替换所有 `replace_with_your_...` 占位实体 ID，
   同一个按钮在 `entity` 和 `tap_action.target.entity_id` 中出现两次，两处都要替换。
3. 打开要使用的仪表盘，进入 **编辑 → 添加卡片 → 手动**，粘贴替换后的整份 YAML。
   这是单张 `vertical-stack` 卡片，不要粘贴到完整仪表盘的原始配置根部，也不要覆盖现有仪表盘。
4. 在预览中核对名称、数值和可用选项再保存。不要为检查布局点击真实控制按钮。
   手机端会以三列显示控制按钮，其他内容纵向排列。

| 占位后缀（省略 `replace_with_your_minij_`） | 在设备页面查找的实体 |
| --- | --- |
| `status` / `reported_program` / `reported_process` | 状态／设备上报程序／设备上报进程 |
| `remaining_time` | 设备上报剩余时间 |
| `program` | 待启动程序 |
| `water_level` / `temperature` / `rinse` | 水位／温度／漂洗对应的参数选择实体 |
| `drying` / `drying_strength` / `steam` / `uvc` | 烘干／烘干强度／蒸汽除菌／UVC 筒灯对应的参数选择实体 |
| `wake` / `start_program` / `pause` / `resume` / `power_off` | 唤醒／启动待选程序／暂停／继续／停止／关机按钮 |
| `start_cleaning` | 启动筒清洁按钮 |
| `prompt_tone` / `child_lock` | 提示音／童锁开关 |
| `device_notification` | 设备通知事件实体 |

参数名来自设备元数据，可能与表中简称不同；请以设备页面实际实体为准。
不存在或不使用的参数可删除对应行；其他机型未必提供本模板中的全部实体。
若实体已被手动禁用，可在实体设置中启用，或从卡片删除该行。
“找不到实体”通常表示占位符尚未替换、实体被禁用或设备未提供它，并不是模板能自动发现实体。

## 显示和操作的含义

- **机器上报程序**是云端最近读回的程序；**待启动程序**是本地草稿，两者可以不同。
  选择程序本身不启动机器。草稿不跨重载保存，启动前请明确选择并核对。
- 原生参数下拉框直接读取集成提供的当前允许值。切换程序后跟随元数据刷新，
  不提供某参数时可能显示不可用；模板不硬编码可选项，也不替机器选择默认值。
- **修改参数会立即发送设置请求**，不是只编辑本地草稿。模板没有“一键设置全部参数”。
- 启动、停止／关机和筒清洁按钮均有确认弹窗；暂停、继续与唤醒点击即调用对应按钮。
  长按和双击未配置控制。模板不主动启动、不定时重发，也不自动唤醒。
- 状态通常每 60 秒读取一次，命令被接受后可能暂时仍显示旧状态。不要连续点击补偿延迟。
  暂停、待机时剩余时间显示未知属于当前支持范围；空闲时程序/阶段可能保留上次值。
- “最近一次官方消息”的时间是 HA 处理事件的时间，不是机器精确结束时间。
  要推送手机，请另外配置[通知蓝图](automations.md)，添加卡片不会创建通知。

配置依据：[实体卡片](https://www.home-assistant.io/dashboards/entities/)、
[卡片动作与确认](https://www.home-assistant.io/dashboards/actions/)。
模板静态结构检查与真实 HA 通知自动化回归不能代替不同手机/浏览器下的实际显示验收。
