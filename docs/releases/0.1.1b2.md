# 小吉 MiniJ 0.1.1b2 · 设备信息同步修复

本版修复云端设备名称、型号或固件版本改变后，HA 仍保留首次加载信息的问题。
成功轮询现在同步已有设备的上报信息，无需重载集成。

用户在 HA 自定义的设备/实体名称、区域，以及设备和实体标识继续保留。
更新复用原来每分钟一次的读取，不增加 API 请求，不控制设备，也不安装固件。
元数据变化仅通过合成 API 与真实 HA 注册表测试；没有更新真实设备固件。

更新前备份，在 HACS 选择此测试版下载并重启，保留现有条目。
实际可下载版本以 GitHub Releases 为准；此文件本身不代表已发布。
更新后请检查原五个实体和设置是否保留。

已记录所有者的 0.1.1b1 HACS 安装、真实 HA 启动恢复和手机 App 保持会话结果。
长期有效期、其他会话轮换、独立用户安装仍待验证。
其余限制与上一版一致：不提供完成通知、剩余时间、物理离线判断或设备控制。
不必为了试用额外运行洗涤。
