# 小吉 MiniJ 0.1.1 · 首个云端监测版

非官方集成，限定支持已验证的 **V6-XNB**（`minij.washer.x68`），
Wi-Fi `1.0253`、设备固件 `0 0003 1 0000`。需要 HA **2026.10.4+**。
其他型号、固件和账号行为尚未全面验证，详见
[支持范围](https://github.com/ajaxjiang96/ha-minij/blob/main/docs/support.md)。

## 本版范围

- 手机验证码/高级令牌登录，同账号重新认证与重新配置。
- 状态、上报程序、上报进程、童锁和云端控制授权五个只读实体。
- 每分钟共享读取，云端失败/解绑显示不可用；未知值不猜测。
- 成功读取后同步名称、型号和固件，保留用户自定义名称、区域及设备/实体身份。
- 白名单缓存诊断，简体中文文档和中英文界面。

运行逻辑沿用 0.1.1b2；本次增加稳定发布渠道、验收记录、支持政策和自动化示例。
测试版所有者已反馈 HACS 升级可用。前后截图显示设备名称、区域、固件及五个实体一致，
升级后本地图标正常；截图不能单独证明所有原始 ID 或自动化引用均未变化，
身份保留另有真实 HA 运行时的合成数据回归覆盖。
已观察到一次 HA 启动后自动恢复，无需短信；所有者确认手机 App 本次仍保持登录。

## 安装和升级

推荐 [HACS 自定义仓库](https://github.com/ajaxjiang96/ha-minij/blob/main/docs/hacs-installation.md)。
本版实际发布后不需要开启测试版开关即可选择稳定标签 `v0.1.1`。
手动安装将 `ha-minij-0.1.1.zip` 解压至 HA 配置目录，校验附件 `SHA256SUMS`。
保留已有条目，下载后重启并刷新浏览器，检查原有实体和设置。

## 已知边界

不提供正常完成事件/通知、剩余时间、物理离线判断、设备控制、固件更新或 LAN/MQTT。
空闲程序/进程可残留；自然过期、真实重新认证、多用户独立安装和长期使用仍需反馈。
监测范围不承诺这些尚未验证的功能。无需为了继续使用额外启动洗涤。

HACS 更新弹窗可能显示图标占位，设备页面本地图标正常；这是图标来源差异，
不影响监测。示例仅在用户自行配置后，针对“空闲→工作”的原始上报变化创建 HA 内部通知，
未在用户生产环境自动创建或执行。

此说明和 manifest 是发布准备；实际发布以 GitHub Releases 和标签为准。
