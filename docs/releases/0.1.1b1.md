# 小吉 MiniJ 0.1.1b1 · 首个监测测试版

非官方云端监测集成，已验证型号为 **V6-XNB**（`minij.washer.x68`），
Wi-Fi `1.0253`、设备固件 `0 0003 1 0000`。需要 Home Assistant **2026.10.4+**。
其他型号可以反馈，不能仅凭安装成功认定受支持。

## 本版功能

- 手机验证码登录、高级令牌登录、同账号重新认证与重新配置。
- 状态、设备上报程序、设备上报进程、童锁、云端控制授权五个实体，每分钟共享一次读取。
- 云端故障/解绑时显示不可用，恢复和重新认证保持实体身份。
- 白名单缓存诊断，不额外请求网络，不复制账号凭据或小吉标识符。
- 简体中文优先的安装、排障、验证说明与问题模板，HA 界面支持简体中文和英文。

## 安装

推荐通过 [HACS 自定义仓库](https://github.com/ajaxjiang96/ha-minij/blob/main/docs/hacs-installation.md) 添加 `ajaxjiang96/ha-minij`，
选择集成类型并启用测试版显示，选择 `v0.1.1b1` 下载后重启 HA。
这不是 HACS 默认列表收录。

手动安装请将 `ha-minij-0.1.1b1.zip` 解压到 HA 配置目录，
最终路径应为 `custom_components/minij/manifest.json`。
`SHA256SUMS` 用于核对附件完整性，不是独立签名。

原来手动安装的用户可以让 HACS 管理同一目录；更新前备份，不删除现有集成条目、设备或实体。
更新后刷新浏览器，防止旧翻译缓存导致空白菜单。

## 已知限制

这是监测测试版，不提供启停、程序选择、固件更新、局域网控制或 MQTT。
“运行 → 空闲”尚未区分正常完成、取消和停止，因此不提供完成事件或默认通知。
空闲程序/进程可能保留旧值；不提供未经验证的剩余时间或物理离线判断。

真实所有者反馈短信流程可用；App 会话影响、HA 重启后的长期会话、额外挑战和限流规则
仍未完整确认。令牌自然失效时使用原账号重新认证，不假设刷新接口或固定有效期。
无需为继续试用额外运行洗涤，正常使用时补充观察即可。
