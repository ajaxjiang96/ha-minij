# 小吉 MiniJ 0.5.0b1 · 自定义卡片与通知蓝图测试版

本版新增 MiniJ 专用卡片和官方消息通知蓝图，沿用0.4.0b5已验证的后端监测与控制能力。
需要 Home Assistant 2026.10.4+；当前仍只在一台 V6-XNB 上取得所有者验证，不提升为全型号稳定版。

![MiniJ 卡片浅色和深色](https://raw.githubusercontent.com/ajaxjiang96/ha-minij/v0.5.0b1/docs/images/minij-card.png)

*截图为合成数据交互演示，不是实时机器状态。*

## 本版新增

- 水滴形 SVG 洗衣机线稿、深浅主题、遵循减少动态效果设置的滚筒动画。
- 可视化编辑器选择一个状态实体，自动关联同设备控件；主按钮随状态切换，程序/参数使用当前允许值。
- 区分本地程序草稿、请求被接受与目标状态读回；启动/停止/筒清洁确认，过时确认取消；未知当前值不阻挡有效参数选择。
- 完成/筒清洁/故障通知蓝图，默认创建 HA 内部通知，也能配置手机 App 通知动作。

## 三个附件分别安装

1. 后端：HACS 自定义仓库中启用测试版并选择 `v0.5.0b1`；手动用户解压 `ha-minij-0.5.0b1.zip` 到 HA 配置目录。后端控制代码与b5相同，原条目和实体标识保留。
2. 卡片：下载 `minij-card.js` 放到 HA 的 `www/`，登记 `/local/minij-card.js?v=0.5.0b1` 为 JavaScript 模块，刷新后添加 MiniJ 卡片。
3. 通知：导入 `minij-device-notification.yaml`，选择洗衣机、消息类型和通知动作；需要用户自行保存启用。

HACS Integration 不会自动安装前端 JS 或创建自动化。已有b5用户也可只安装卡片和蓝图。
更新前备份；用 `SHA256SUMS` 核对三个附件。已有卡片候选用户应替换 JS 并更新资源 URL 的版本值。

## 验证与限制

457项 Python 回归和13项前端行为测试通过。所有者真实 HA 已验证卡片资源加载、编辑器、实体自动关联及状态/参数显示，并反馈显示效果正常；新卡片的设备操作及真实手机推送仍需日常使用反馈。
HA 编辑预览禁用设备写入；保存后才可主动控制。参数修改会立即提交，待启动程序本身仅为本地草稿。
状态通常每60秒刷新；不乐观改状态、不自动重试，不从待机或时间归零推断完成。
完成消息在首次/恢复时不补报历史；暂停/空闲时间显示未知，不提供预计结束时间或物理离线判断。

稳定渠道仍为早期监测版0.1.1。童锁面板效果、长期会话和其他型号/固件不因本版发布而视为已验证。
