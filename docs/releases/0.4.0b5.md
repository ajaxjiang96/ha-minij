# 小吉 MiniJ 0.4.0b5 · 云端监测与控制测试版

本版将集成从早期状态监测扩展为监测与控制，使用已在 V6-XNB 所有者 HA 本地验收的 b5 运行代码。
这是预发布版本，稳定渠道仍为0.1.1。需要 Home Assistant 2026.10.4+、已绑定设备的小吉账号及云端连接。

## 主要功能

- 新增唤醒、启动待选程序、暂停、继续和停止／关机；App 的停止确认与菜单关机是同一请求。
- 设备元数据提供程序及动态参数，本机发现22程序、7类参数；按程序读取对应选项。
- 待启动程序为本地草稿，选择本身不操作机器；暂停／继续单独读取实际运行程序，避免误用草稿。
- 提示音、童锁与智能清洁设置/动作；部分设置仅在设备提供声明时出现。
- 延续状态、程序/阶段、工作时剩余分钟和官方完成/故障消息事件；新增“已暂停”状态翻译。
- Diagnostics 增加最近30条脱敏控制请求与缓存参数摘要，重启/重载后清空请求历史。

本轮 V6-XNB 共25实体。新控制默认启用，保留既有 HA 用户设置与原设备/实体标识。
请求只发送一次，不自动唤醒或重试，不把云端接受当作机器已执行。
服务端认证与设备保护仍生效，控制前有绑定、成功读取、有效参数及生命周期检查。

## 本轮验证

所有者确认唤醒、启动和本轮参数有效；暂停按下后立即生效且机器语音播报。
继续后云端恢复工作中，停止／关机后稍有延迟再回待机；提示音已有静音并恢复的现场记录。
童锁已有运行时云端开关变化，面板效果未单独确认。其他程序、枚举、阶段和固件不据此视为全部验证。

合成 API 与真实 HA 回归453项断言通过，Linux最低/当前HA、hassfest、HACS验证成功；
另有所有者本地安装与运行记录。自动化测试与实机验收分别记录，详见[验证记录](../validation.md)。

## 安装与已知限制

HACS 自定义仓库中启用显示测试版，选择 `v0.4.0b5` 下载并重启 HA；手动用户将附件
`ha-minij-0.4.0b5.zip` 解压到 HA 配置目录。更新前备份，保留原集成条目。
已经安装本地b5的用户运行代码相同，可按需通过HACS下载本标签统一版本记录。

- 云端状态可能延迟，程序/进程与时间在空闲时可能残留；回空闲不等于正常完成。
- 完成事件依赖独立官方消息，首次/恢复不重播历史，停机窗口不补报；通知由用户配置。
- 剩余分钟只在已验证型号明确工作时输出，暂停/空闲为未知；不提供预计结束时间或物理离线判断。
- 当前验证来自一台V6-XNB；长期会话、多用户、其他型号和全部参数组合仍待反馈。
- 仅云端连接，不含固件安装、局域网协议或MQTT。

测试控制后先下载 Diagnostics 再重启/重载。分享前检查 HA 外围系统元数据，不上传原始凭据或设备标识。
