## 本机升级检查（所有者方便时）

1. 备份 HA；在本地记下原设备/实体 ID、自定义名称、区域和自动化引用。
2. 按 [HACS 安装指南](hacs-installation.md)选择实际发布的测试版，下载后重启。
   保留条目，不重新登录，不为验收改变洗涤或设备固件。
3. 核对五个实体和原设置。状态界面应按语言显示已知状态；开发者工具仍为原始别名。
4. 程序/进程值继续显示原上报文字；展开属性查看“设备上报运行中”。
   空闲时 false 不表示正常完成；异常或未知时 null 不表示停机。
5. 下载一次诊断，核对最近成功云读取时间和刷新结果；不将诊断导出时间当作机器更新时间。
   不要求提供原始文件、账号或设备标识。
6. 仅查看现有自动化仍引用原实体，不必触发通知、启停或其他设备操作。

## 持续观察记录模板（保存在自己的本地）

| 项目 | 填写内容 |
| --- | --- |
| 开始/结束日期 | 实际使用起止；中途版本变化或长时间停机单独记录 |
| 环境 | 集成版本、HA 版本、型号/固件，不写账号或设备 ID |
| 运行情况 | 是否持续读取、自然出现的错误及恢复；没有错误也如实记录 |
| App 共存 | 日常使用中是否仍登录；不反复登录制造轮换 |
| 设置保留 | 原 ID、名称、区域、自动化引用是否保留，仅分享核对结论 |
| 认证过期 | 未遇到则记未遇到；遇到后记录重新认证结果，不填令牌/手机号/验证码 |

至少 14 天只是首轮观察窗口，不能证明全部服务端行为或令牌有效期。
版本变动时保留分段记录，不将先前未记录的时间当成候选验收。
不需要额外洗涤、断网、限流或撤销会话；认证相关信息只在自己的 HA/App 内输入。

## 独立所有者安装

由另一位真实所有者从中文 README 开始，在自己的 HA 中完成安装、登录、
读取和正常重启恢复；反馈遇到的障碍、型号/版本、是否有五个实体和能否下载诊断。
无需另一账号凭据、完整日志或远程访问权限。没有第二位用户时保持待验收。

自然过期若仍未遇到要继续列限制，不能制造过期或假称已通过。
若需要改变路线图范围，单独记录范围决策，不将未通过项改成已验收。
