| 场景 | 云端白名单字段 | 对照与结论 |
| --- | --- | --- |
| 历史空闲 | `resting`、主洗、剩余 `48`、总时间 `48` | 空闲时间及进程可残留，不可显示成运行倒计时 |

| 同次 App 对照 | 所有者确认剩余显示 `00:57` | 当前 V6-XNB 运行场景的 `program_remain_time` 单位为分钟 |

数字是观察到的值，不是固定配置或所有程序的约定。总时间 `65` 尚无单独 App 总时长对照，
保留为诊断原值。`current_process_alias: main_wash` 与主洗本次配对；其他别名未据此猜测。

0.3 候选仅在型号为 `minij.washer.x68` 且状态明确 `working` 时提供剩余分钟数。
空闲、异常、其他/缺失状态和无效值为未知，云端失败或解绑为不可用。
每次只显示实际读到的值，不在本地自行递减；`0` 不触发完成。
未知数字哨兵值和不同固件/阶段的行为仍需核对，不能将整数有效性当作所有业务值语义已证实。

## 还未确认，不能替代

- 正常完成、暂停、继续、取消的原文/别名及云端字段之间的对应。
  所有者确认 App 有相关显示，但尚未提供逐项原文；不能将“都有”当作枚举表。
- 能否稳定区分正常完成与其他回空闲原因，是否有可识别周期 ID 或可恢复事件历史。
- 暂停时是否仍报告 `working`、时间是否冻结；其他阶段、烘干和固件的时间行为。
- `fault_code` 的值、具体故障含义、在线标志的时效及物理联网语义。

因此本候选没有正常完成事件、预计结束时间、具体故障翻译或物理离线判断。
