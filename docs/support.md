# 支持范围与反馈政策

首个稳定版目标为**有限机型的云端状态监测**，不是通用小吉控制平台。
稳定版名称表示所列功能的发布渠道，不表示所有机型、账号或服务端行为都已验证。

## 支持矩阵

| 项目 | 范围 |
| --- | --- |
| 已验证设备 | V6-XNB 壁挂洗烘机，内部型号 `minij.washer.x68` |
| 已观察固件 | Wi-Fi `1.0253`，设备固件 `0 0003 1 0000` |
| HA | 最低 2026.10.4，CI 覆盖最低与当前发布版本 |
| 连接 | 小吉云 API，每 60 秒共享读取，不支持本地离线运行 |
| 登录 | 中国大陆 11 位手机号验证码，或自己的现有 App 会话令牌 |
| 实体 | 状态、上报程序、上报进程、童锁、云端控制授权 |
| 安装 | HACS 自定义仓库，或发布附件手动安装 |

其他型号/固件可以提交脱敏观察，不因安装成功就标记为支持。
当前真实设备验收来自一位所有者；其他用户的独立安装和长期使用反馈仍待补充。

## 状态和可用性

状态保留云端原始别名。空闲程序/进程可能残留，不能由“主洗”“脱水”推断仍在洗涤。
`working → resting` 不足以确认正常完成，当前没有完成通知、剩余时间或设备控制。
云端读取失败或解绑会显示不可用，不等于已证实物理离线。

认证拒绝触发同账号重新认证，云端故障不会自动发送短信。
真实重新认证、所有挑战、长期有效期和多客户端轮换规则尚未完整验收；
HTTP 401/403 之外的未知业务错误不猜测为过期，没有假设的自动刷新接口。

## 反馈方式

使用中文 Issue 模板，说明版本、型号/固件、安装方式和复现情况。
诊断仅使用白名单缓存，但 HA 外围仍有系统元数据，分享前检查。
不上传令牌、验证码、手机号、账号/设备标识、姓名、原始账号响应或抓包。

维护者不承诺官方云 API 长期不变，也不承诺固定响应时限。
变更保持设备和实体身份稳定；回归优先修复，新增能力以真实证据为准。
HACS 默认列表收录、多用户/更多机型、完整周期语义属于后续验证，不作为已完成宣传。

## HACS 更新弹窗的图标占位

设备/集成页面使用组件自带 `brand/icon.png`，已有用户升级后截图显示正常。
HACS 更新实体目前使用 `brands.home-assistant.io/_/minij/icon.png`；
已读取到该地址返回“icon not available”占位图。这与组件本地图标是两条加载路径，
不影响登录、实体或更新包完整性，不要求用户反复重装。

依据：[HACS 更新实体源码](https://github.com/hacs/integration/blob/main/custom_components/hacs/update.py)、
[HA 本地图标机制](https://contributors.home-assistant.io/core/integrations/brands/)。
